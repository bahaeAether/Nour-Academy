# Nour Academy — Portail d'inscription

Portail web de Nour Academy, réseau de trois centres de soutien scolaire et de langues à Nador. Le site permet aux parents de consulter les cours disponibles et de préparer l'inscription de leurs enfants depuis leur téléphone.

## Fonctionnalités

- Catalogue : affichage dynamique des cours avec matière, niveau, créneau, prix et places restantes.
- Cours complets : identification des cours sans places disponibles et désactivation de leur bouton.
- Sélection des cours : ajout et retrait des cours, avec calcul du total mensuel.
- Formulaire d'inscription : validation des informations du parent et de l'élève.
- Confirmation : récapitulatif du dossier d'inscription.

## Technologies

HTML5 sémantique, CSS3 natif (Flexbox, Grid, variables CSS et responsive design) et JavaScript natif. Aucune bibliothèque ni aucun framework JavaScript.

## Design

Interface mobile first, avec une charte graphique basée sur le vert foncé, le vert clair et le blanc cassé. Le site est conçu pour s'adapter aux écrans de 360 px à 1440 px.
